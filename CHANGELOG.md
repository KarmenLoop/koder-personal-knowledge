## 1.0.0 — 2026-10-19

Initial release.

- Portable skill for gradual, source-backed personal knowledge accumulation.
- Local SQLite records and a managed, hash-addressed reference library.
- Bounded keyword retrieval, paged body reads, and readable offline views.
- Fact/inference separation, source-preserving corrections, and event deduplication.
- Space grants for verified principals, with owner-controlled sharing and revocation.
- Record deletion with view cleanup and event tombstones.
- English documentation, tool help, viewer labels, and synthetic examples.
- Local regression tests, a runnable walkthrough, and release packaging tools.

Host invocation, real messaging adapters, document extraction, and cloud synchronization are separate integration work. See [validation notes](docs/validation.md).
