# Support

Use [GitHub Issues](https://github.com/KarmenLoop/koder-personal-knowledge/issues) for reproducible bugs, documentation gaps, and feature requests. Questions are welcome in Discussions if the maintainers enable it.

Before opening a report, check the [FAQ](docs/faq.md) and [command reference](koder-personal-knowledge/references/commands.md). Include your OS, Python version, project version/commit, the command structure, exit code, and a small synthetic example.

Replace real owner, tenant, conversation, and file identifiers with synthetic ones. Do not attach the database, original documents, owner-wide HTML/JSON views, credentials, or unredacted logs.

For channel delivery issues, identify the host adapter and where the failure occurs. This project can help with its local tool; the host owns channel login, signatures, identity mapping, and message transport.

For sensitive reports, use [SECURITY.md](SECURITY.md). No external email, donation address, commercial support contract, or response-time promise is implied by this repository.
